# LingoMate

Interactive English & Mandarin Chinese learning PWA.

## Features
- English & Chinese learning paths
- Interactive lesson mini-quizzes
- Grammar, reading, listening, speaking, and writing practice
- Browser speech recognition and speech synthesis
- Tutor correction rules for common English/Chinese mistakes
- Personal Error Notebook
- Dictionary + personal wordbook
- Local progress persistence
- Responsive mobile/desktop UI
- Installable PWA over HTTPS

## Deployment
Production is intended to run on Royyan's home server behind Nginx + Cloudflare Tunnel. Pushes to `main` can be deployed by the self-hosted GitHub runner after the LingoMate runner label/deploy script is configured.

TOEFL/IELTS-style practice is original practice inspired by common task types and is not official exam content.
